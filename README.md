##  How to Run

1. Clone the repository:
```bash
git clone https://github.com/RemasAlmania/AraNLP.git
cd AraNLP
```

2. Open any `.ipynb` file in **Google Colab** or **Jupyter Notebook**

3. Install required dependencies (each notebook has its own `pip install` cells)
